RSA Encryption (Small Example)

Widely Used Public-Key
HI (M = 72,73)
→
1394
P=53, Q=59
n=3127, e=3, d=2011
1Choose two primes: P = 53, Q = 59
2n = P × Q = 3127  |  φ(n) = (P-1)(Q-1) = 3016
3Choose e = 3 (gcd(3, 3016) = 1) → Public key (e=3, n=3127)
4Find d such that d × e ≡ 1 (mod φ(n)) → d = 2011 → Private key
5Encrypt: C = M^e mod n = 72^3 mod 3127 = 1394
6Decrypt: M = C^d mod n = 1394^2011 mod 3127 = 72 ✓

Diffie-Hellman Key Exchange

Key Exchange Asymmetric
p = 23 (prime)
g = 5 (generator)
↔
2
Alice: a = 6
Bob: b = 15
1Alice computes: A = g^a mod p = 5^6 mod 23 = 8 (sends to Bob)
2Bob computes: B = g^b mod p = 5^15 mod 23 = 19 (sends to Alice)
3Alice's secret: s = B^a mod p = 19^6 mod 23 = 2
4Bob's secret: s = A^b mod p = 8^15 mod 23 = 2 ✓ Same secret!
5An eavesdropper sees p, g, A=8, B=19 but cannot derive s without solving the Discrete Logarithm Problem.

AYUSH
1Key "AYUSH" is repeated to match plaintext length: A Y U S H A Y U S H A Y U
2Each letter pair (plaintext, key) is added mod 26: G+A=G, E+Y=C, E+U=Y, K+S=C, S+H=Z...
3Formula: Cᵢ = (Pᵢ + Kᵢ) mod 26 per position.
4Unlike Caesar, different key letters shift each position differently — defeating frequency analysis.

1Build a substitution alphabet starting with unique letters of "KEY": K E Y...
2Append remaining unused letters in order: K E Y A B C D F G H I J L M N O P Q R S T U V W X Z
3Map each plaintext letter to its position in the substitution alphabet.
